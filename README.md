# 推箱子 Sokoban（Unity 2022.3）

一个按产品标准制作的推箱子游戏：完整的关卡流程 + 功能完备的关卡编辑器 + 内置求解器（可解性校验 / 提示 / 死局检测）。
美术与音效全部由代码程序化生成（临时资源），工程不依赖任何外部素材或第三方插件。

- 引擎：**Unity 2022.3.51f1**（2022.3 LTS 任意小版本均可）
- 平台：Windows / macOS（PC，键鼠操作）
- 打开方式：Unity Hub → Add → 选择本目录 → 打开后运行 `Assets/Scenes/Main.unity`（已加入 Build Settings）

---

## 功能一览

### 关卡体验流程
| 模块 | 内容 |
|---|---|
| 主菜单 | 开始/继续游戏（自动定位到下一未通关关卡）、选择关卡、关卡编辑器、设置、退出；显示总进度与星级 |
| 选关 | 官方关卡 / 自定义关卡两个分页；逐关解锁；卡片显示星级、最佳步数、尺寸与箱子数 |
| 游戏 | 键盘移动（按住连续移动）、鼠标点击地面自动寻路、点击相邻箱子推动；无限撤销/重做、重开；步数/推动/箱子/计时 HUD |
| 提示 | 后台线程运行求解器，自动走到并完成“下一次推动”；若当前局面已无解，弹窗建议撤销/重开 |
| 死局提醒 | 推动后即时检测“死格”和 2×2 冻结死锁，提示玩家撤销 |
| 结算 | 按参考步数评 1~3 星，记录最佳步数/推动/用时，新纪录提示，下一关/重玩/返回 |
| 设置 | 音效开关与音量、动画速度、死局提醒、全屏、解锁全部关卡、重置进度 |
| 存档 | `persistentDataPath/save.json`（原子写入，损坏时自动回退） |

内置 21 个关卡，由浅入深（1~5 箱）：前半为手工设计的教学关，后半由“逆向拉箱”生成器产出、经求解器挑选。
**每一关都经过求解器验证可解**，参考步数 `Par` 即求解器给出的推动最优解的步数。

### 关卡编辑器
- 5 种绘制工具（墙壁 / 地板 / 目标点 / 箱子 / 玩家），左键拖拽绘制、右键擦除，快速拖动自动插值不漏格
- 尺寸调整（3×3 ~ 30×30）、整体平移、自动围墙、裁剪空白
- 编辑撤销/重做（Ctrl+Z / Ctrl+Y）
- 实时结构检查：玩家数量、箱子与目标数量、区域是否封闭、是否有箱子/目标在不可达区域等
- **可解性检查**：后台线程求解，给出最少推动次数与参考步数；保存时自动校验，无解关卡会提示
- 一键试玩（F5），试玩结束直接回到编辑器，编辑状态保留
- 保存 / 另存为 / 打开 / 删除；可打开官方关卡副本作为模板
- 导入/导出标准 XSB 文本（剪贴板），可与其它推箱子软件互通
- **随机生成关卡**：逆向拉箱算法 + 求解器评分，保证可解

自定义关卡保存在 `persistentDataPath/CustomLevels/*.xsb`（可直接用文本编辑器查看）。

## 操作
| 操作 | 按键 |
|---|---|
| 移动 / 推箱 | 方向键 或 WASD（按住连续移动）；鼠标左键点击地面寻路、点击相邻箱子推动 |
| 撤销 / 重做 | Z（或退格、鼠标右键） / Y |
| 重开 / 提示 | R / H |
| 暂停菜单 | Esc 或 P |
| 下一关（已通关时） | N |
| 编辑器 | 1~5 切换工具，Ctrl+Z/Y 撤销重做，Ctrl+S 保存，F5 试玩，Esc 返回 |

## 工程结构
```
Assets/
  Scenes/Main.unity                 唯一场景，只挂一个 App 组件（组合根）
  Resources/Levels/BuiltIn.txt      内置关卡（标准 XSB 文本 + Title/Id/Par 元数据）
  Scripts/
    Core/      Sokoban.Core.asmdef  纯 C# 逻辑，noEngineReferences，可单测
      LevelData.cs        关卡数据 + XSB 解析/序列化
      SokobanGame.cs      规则、撤销/重做、寻路
      Solver.cs           推动级 BFS / 贪心最佳优先求解器（死格 + 2×2 冻结剪枝，Zobrist 去重）
      DeadlockDetector.cs 游戏中的即时死局检测
      LevelValidator.cs   编辑器结构校验
      LevelGenerator.cs   逆向拉箱随机关卡生成
    Game/      Sokoban.Game.asmdef  Unity 表现层
      App.cs              组合根：相机、画布、服务、屏幕切换、相机自适应
      BoardView.cs        精灵渲染与移动动画
      SpriteFactory.cs    程序化生成的临时美术
      SfxPlayer.cs        程序化合成的临时音效
      SaveSystem.cs / LevelRepository.cs  存档与关卡仓库
      UI/                 代码构建 uGUI（UIFactory、Modal、Toast）
      Screens/            主菜单 / 选关 / 游戏 / 编辑器 / 设置
    Editor/    菜单 Sokoban/…：验证全部内置关卡、重算参考步数、打开/清除存档
  Tests/EditMode/  NUnit 单元测试（Window → General → Test Runner → EditMode → Run All）
```

设计要点：
- **逻辑与表现分离**：规则、求解、生成全部在无引擎依赖的 Core 程序集中，表现层只负责渲染和输入，便于测试和移植。
- **UI 全部由代码构建**：没有 prefab/场景引用会失效，版本管理中的差异清晰可审阅。
- **重计算不卡帧**：求解/生成在后台线程运行，可取消；结果按状态版本号校验，过期结果自动丢弃。

## 关卡文本格式
```
Title: 关卡名
Par: 42
#######
#.@ $ #
#######
```
`#` 墙　`@` 玩家　`+` 玩家在目标上　`$` 箱子　`*` 箱子在目标上　`.` 目标　空格 地板。多个关卡以空行分隔。
